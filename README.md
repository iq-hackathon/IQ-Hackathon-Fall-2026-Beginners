# IQ-Hackathon-Fall-2026-Beginners
Official repository of Interstate Quantum Hackathon for Beginners in Fall 2026

All notebooks and links to recordings for IQ Hackathon will be shared in this repository.

The challenges will also be published here once the training is over.

There are different ways to run the notebook. The most convenient and suggested way is to use [Google Colab](https://colab.research.google.com/) for the notebooks. In Colab, there are different ways of opening the notebook.

1. Open Colab, click on Upload Notebook, you can either upload directly from your computer or go to the Github tab and copy and paste the Github url for the notebook.
2. Click the sharable link and open it on colab. Then use the "Copy to Drive" button in the top panel (Same panel with Command, Code,...). The sharable link will be sent out in the emails to the participants.
